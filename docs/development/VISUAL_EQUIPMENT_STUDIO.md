# Visual Combat & Equipment Studio

Open Developer Tools → Studios → Items → Combat & Equipment → Open Combat & Equipment Studio. Select a built-in game item to edit its runtime tuning. The surrounding catalog manages merchandise, prices, inventory and vendor assignments. In particular, the M1 and M2 price controls in the Studio refer to Admin’s ship ordnance refills. Editing equipment never grants ownership.

Each card shows the settings used by the selected item. Use the practice target for direct damage, the orange handle for splash size, the blue handle for turning and the target marker to change the encounter. The flight view uses a stationary reference ship, a locked practice target and game units. The gray line runs a copy of the same preview ahead. It uses the game's ordnance definitions, launch, movement, hit and expiry code. Actual encounters can include pilot upgrades, collisions, skirmish modifiers and multiple ships. A base deflector starts at the Kestrel’s default of zero. Set capacity or select Aegis to test recharge.

The game and preview share damage allocation, absorption, recharge, splash falloff and power-bank consumption. Editable response curves cover shield recharge by charge level, splash by distance, laser damage by range and fitted pulse-coil energy use by charge level. The curve editor also serves the Consumables Studio. The Ward pistol uses its on-foot health model. Space combat uses shield and armored hull. Equipment profiles use the existing game sound and impact effect identifiers.

**Persistence.** Save local draft stores a private project in the current browser under the developer UID. Equipment presets also belong to that developer and browser. Export/import transfers the tuning project as JSON. Publish tuning uses the authenticated, revision-checked combat balance API. Changing the draft or running a simulation never applies tuning to the game. A successful publish takes effect at the existing game balance boundary. The original Combat Balance panel can continue saving scalar changes and preserves equipment profiles written by this Studio. Existing saves and catalog item schemas need no migration.

**Coverage.** The built-in library includes the Ward pistol, pulse laser, Wraith, M1, M2, both refill prices, hull plating, standard deflector, Aegis, capacitor and pulse coils. Gameplay keeps the existing arcade guidance and supported sound cues. A separately authored catalog item does not acquire a new combat behavior merely by selecting a merchandise category.

Run `node --test tests/equipment-profiles.test.cjs` for the game calculations and `node tests/equipment-studio-browser.cjs` for Chromium and Firefox. Set `EQUIPMENT_SCREENSHOTS` to an existing directory to capture both browsers. API tests cover an older balance editor writing after a new one, invalid settings, public reads and revision conflicts.

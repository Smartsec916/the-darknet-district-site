## Game and website integration

- `tools/blackout-tesana/` contains the exported TypeScript game, original painted backgrounds, level-specific ads, Level 3 female NPCs, and `build-and-sync.sh`. The build outputs the same game to GitHub Pages `blackout-protocol/` and Render `static/blackout-protocol/`. The 123 MiB `references/` archive and unused storefront art/metadata are excluded. The website's existing `games-list.html` link and other games remain unchanged.
- All 12 sector definitions, controls, animations, menus, effects, scoring, local save/progression, and mobile touch controls remain in the game. Original point values are unchanged: coins 10, shards 50, relay sync 250, hacks 150, enemy values 100–400, bosses 5000, plus the completion time bonus. Guest progress retains the export's original browser save key; each signed-in Firebase UID has a separate local key. Switching accounts reloads the game into the correct save. Local saves stay in the browser, including when ranked services are offline.
- The export's separate Tesana play SDK was removed. The new Account / Top 100 panel uses copies of the website's existing Firebase and District identity modules. It shows the public handle, best score/rank, and Top 100 when those services work. A new signed-in campaign starts a ranked run; guest and resumed campaigns play locally without claiming a ranked score. When account or leaderboard services fail, the UI visibly says **LOCAL PLAY · RANKINGS OFFLINE/UNRANKED** and states that no score was submitted. Rejected submissions never appear as accepted.
- `blackout_api.py` provides `/api/blackout/v2/leaderboard`, `/v2/runs`, and `/v2/runs/<id>/level`. Version `tesana-2026-11-06` uses separate `bp_tesana_*` collections. The legacy account/handle registry is shared, while old score records remain untouched and off the new board. The server verifies Firebase ID tokens and public handles, owns player/run IDs, enforces ordered sectors and minimum durations, recalculates score from bounded Tesana events, requires boss events in boss sectors, deduplicates submissions, and returns Top 100 plus personal rank. Browser event evidence is constrained but cannot cryptographically prove gameplay. Accepted server records carry stable game ID/version and structured milestone events for later achievements.

# VOID//RUNNER: Third-Party 3D Asset Licences

Every third-party model, texture or HDRI in the game is listed here before it ships.
- **Licence is pass/fail:** commercial use must be allowed.
- **Not allowed:** anything extracted from commercial games, and anything without a clear licence.

**Fields:**
- asset name, creator, source URL
- licence, attribution required (yes/no), modification and redistribution terms
- download date, local path, approval status

measures to prevent the end user from gaining access to the Product", for example "encrypting the Product data".
Subscription downloads (§19A.12) may be used after a subscription ends only in projects completed while it was active,
and always under the No AI licence (§19A.19). So: the converted models (never the downloads) live in the private
repository `Smartsec916/void-runner-licensed-assets`; `.github/workflows/pages.yml` publishes the site from GitHub
Actions, adding them encrypted with AES-256-GCM (`tools/assets/build-pages.cjs`; key in the repository secret
`VOID_ASSET_KEY`, written into `asset-pipeline.js` at deploy). The browser must hold the key to draw a model, so a
determined player can still extract it; this is the commercially reasonable measure, not protection. Nadia's
scrambled model has been in this public repository since 2026-10-28 and stays there (it is free, Royalty Free no AI);
the deployed copy is encrypted like the others.
